# Print files

Organised by pack, then global:

- `welcome/`: A6 pack card, belly band, sticker, breathing cards.
- `steady/`: A6 pack card, belly band, sticker, reflection prompt cards.
- `onward/`: A6 pack card, belly band, sticker, A5 leaflet.
- `global/`: (to come) general leaflet/flyer, centre info sheet, social templates.

Each pack folder has `klaire-packs-<pack>-print-files.zip` containing all of that pack's PDFs. These are the original Canva exports from Luke Renton, unchanged.

Pack background colours: Welcome uses light terracotta #E4B58C; Steady uses sage #6E7D5B; Onward uses clay #9C6A3F.
